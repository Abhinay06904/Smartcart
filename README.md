# SmartCart - Customer Segmentation Using Machine Learning

## Overview

SmartCart is a Machine Learning project focused on customer segmentation analysis using clustering techniques. The project analyzes customer purchasing behavior and groups customers into different segments based on similarities in their shopping patterns.

The main objective of this project is to help businesses better understand customer behavior and improve decision-making through data-driven insights.

---

## Features

- Customer data preprocessing
- Exploratory Data Analysis (EDA)
- Feature scaling and normalization
- Principal Component Analysis (PCA)
- K-Means Clustering
- Cluster visualization and interpretation

---

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## Machine Learning Workflow

### 1. Data Collection

The project uses a customer dataset containing shopping-related information.

### 2. Data Preprocessing

- Handling missing values
- Feature selection
- Data normalization

### 3. Exploratory Data Analysis

Visual analysis of customer trends and distributions.

### 4. Dimensionality Reduction

PCA (Principal Component Analysis) is applied to reduce dimensionality and improve clustering performance.

### 5. Customer Segmentation

K-Means Clustering is used to divide customers into multiple groups based on behavioral similarities.

### 6. Visualization

Clusters are visualized using graphs and scatter plots for better interpretation.
